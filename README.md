# 瀑布流图片浏览器（Masonry Image Viewer）

一个纯前端、零依赖的本地图片浏览工具。通过瀑布流（Masonry）布局展示图片，支持直接读取本地文件夹，无需上传服务器，所有操作都在浏览器本地完成，保护隐私。

## 特性

- **本地读取，隐私安全**：基于 File System Access API，直接读取本地图片文件夹，图片不会离开本机。支持拖入文件夹、粘贴图片、或点击选择文件夹三种方式导入。
- **瀑布流布局**：图片按列自动排列，自适应填充空白，整齐美观，适合浏览大量不同尺寸的图片。
- **两种排列方向**：
  - 纵向（列优先）：按固定列数排布，适合桌面浏览。
  - 横向（行优先）：按固定最小高度排布，适合连续浏览。
- **丰富的布局调节**：可实时调整列距、行距、圆角、边框、列数、最小高度，所见即所得。
- **图片查看**：点击图片进入全屏查看，支持缩放、拖动移动、键盘导航切换上一张 / 下一张。
- **智能筛选过滤**：
  - 黑白漫画：自动识别黑白线条类图片。
  - 纯色边框：筛选带纯色边框的图片。
  - 反转：反转当前筛选状态。
  - 宽高比过滤：按比例精确筛选（如 `16:9`、`16:9-`、`4:3-16:9` 等）。
- **排序与重排**：支持按默认、修改日期、文件大小排序，升序 / 降序自由切换。
- **文件目录树**：左侧目录树可快速跳转到任意子文件夹，支持调整目录栏宽度。
- **懒加载与分页**：按设定数量分批加载，避免一次性渲染过多图片导致卡顿；可随时暂停、一键加载全部、或跳转到指定图片。
- **配置记忆**：所有布局与排序设置自动保存到浏览器本地，下次打开自动恢复。
- **响应式与 PWA**：适配电脑与手机，支持离线缓存，可作为渐进式 Web 应用安装。

## 使用说明

### 导入图片

1. **拖入**：把图片文件夹直接拖到页面上。
2. **粘贴**：复制图片后，在页面内粘贴（`Ctrl + V`）。
3. **点击选择**：点击页面中央提示文字，从系统文件夹选择器中选择图片文件夹。

### 浏览与查看

- 滚动浏览瀑布流图片，鼠标悬停可查看文件名、尺寸、大小等信息。
- 点击任意图片进入全屏查看模式，使用左右按钮或键盘左右键切换图片。
- 使用右下角的箭头按钮快速回到顶部或跳到最后。

### 侧边栏设置

点击左上角 `+` 按钮展开侧边栏，可调整：

- **列距 / 行距**：图片之间的间距。
- **圆角 / 边框**：图片外观样式。
- **列数**：瀑布流的列数（纵向模式）。
- **高度**：最小行高（横向模式）。
- **排序**：排序方式与顺序，点击“重排”应用。
- **过滤**：按黑白漫画、纯色边框筛选，或用宽高比精确过滤。
- **加载**：设置每次加载数量、跳转图片、暂停或加载全部。

所有设置会实时生效并自动记忆。

## 技术栈

- 原生 HTML / CSS / JavaScript，无任何第三方依赖与构建工具。
- File System Access API：读取本地文件夹。
- CSS Grid + Flexbox：瀑布流布局。
- Service Worker + Web App Manifest：离线缓存与 PWA 支持。

## 浏览器要求

建议使用较新版本的 Chrome / Edge，File System Access API 等特性需要现代浏览器支持。
